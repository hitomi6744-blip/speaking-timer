JAPANESE SPEAKING PRACTICE TIMER — FREE WEB APP

IMPORTANT:
This package is a free installable web app (PWA), not a compiled Android APK.
It tracks elapsed practice-session time. It cannot measure actual speaking minutes while ChatGPT/Gemini is using the microphone, because Android typically allows only one app to own microphone input at a time.

FILES
- index.html: the app
- manifest.json: installable app metadata
- sw.js: basic offline cache

EASIEST WAY TO USE
1. Upload these files to a free static HTTPS host (GitHub Pages is one option).
2. Open the hosted index.html link on Android Chrome.
3. Use Chrome menu (⋮) > Add to Home screen / Install app.
4. Launch it from the home screen like an app.
5. Enter student ID, choose target, press Start.
6. Open ChatGPT or Gemini voice conversation, practise Japanese, then return to the timer and press Finish.
7. Copy the session report and send it to the teacher.

No paid API, no login in the timer, no microphone recording, no audio upload.
Free AI voice features and usage limits depend on ChatGPT/Gemini accounts and regional availability.
